마중산업 공식 홈페이지

마중산업(주)의 회사 소개와 건설자재 정보를 제공하기 위해 제작한 공식 홈페이지 프로젝트입니다.

1. 프로젝트 소개

마중산업의 사업 분야와 건설자재 정보를 효과적으로 전달하고, 고객이 회사의 주요 정보와 카탈로그를 편리하게 확인할 수 있도록 제작했습니다.

2. 주요 기능

회사 소개: 회사 정보 및 주요 사업 분야 안내

건설자재 소개: 주요 건설자재의 종류와 정보 제공

카탈로그: 제품 및 회사 소개 자료 열람

게시판: 공지사항 및 게시물 확인

납품실적: 주요 납품실적 안내

반응형 웹 디자인: PC와 모바일 환경에서 편리하게 이용할 수 있도록 개선
